# Where does the trip chat live on the board and on a phone?

## Question

The board now has details, hotels, map and itinerary. Decide where the chat sits (side panel, drawer, bottom sheet) and how it looks on desktop and phone, after the board layout settles.

## Resolution

Closed by delegation: the user dropped the prototypes ("just make app") and asked for the real build. The board keeps its full width; the chat only shows when AI is configured. Prototype files were removed and are not committed.
